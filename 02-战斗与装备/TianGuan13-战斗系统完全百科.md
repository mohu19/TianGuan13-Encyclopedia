## 1.2 拳击 Boxing（C 档）

**机制**：每拳都触发 tussle，伤害 = `rand(手臂低,高) + (运动技能+力量)×倍率`；伤害类型 STAMINA（默认）可被和平主义者使用。

| 连击 | 招式 | 倍率 | 效果 |
|---|---|---|---|
| HH/DD（同侧） | 直拳 | ×1 | 标准拳 |
| HH/DD（异侧） | 轻刺 | ×1 | 无 CD 惩罚 |
| DH/HD（换手） | 左/右勾拳 | ×1.5 | CD ×1.5 |
| 其他 | 上勾拳 | ×1 | 效率 ×1.5 |
| 偷袭（背后） | 偷袭拳 | ×2 | 头部+踉跄 |
| crit（目标踉跄） | 重击 | — | 20s 击倒+10s 睡眠 |
