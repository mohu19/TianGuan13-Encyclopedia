## 职业系统基础

### `/datum/job` 核心字段

| 字段 | 说明 |
|---|---|
| `title` | 职业名 |
| `description` | 职业描述 |
| `total_positions` | 总岗位数 |
| `spawn_positions` | 出生岗位数 |
| `supervisors` | 直属上级 |
| `outfit` | 初始装备 |
| `plasmaman_outfit` | 等离子人版装备 |
| `paycheck` | 工资等级 |
| `paycheck_department` | 发薪部门 |
| `exp_requirements` | 经验要求 |
| `exp_granted_type` | 可获得经验类型 |
| `mind_traits` | 心智特质 |
| `liver_traits` | 肝脏特质(例如警察吃甜甜圈回血) |
| `bounty_types` | 赏金任务类型 |
| `mail_goodies` | 邮件礼物(加权列表) |
| `departments_list` | 所属部门 |
| `head_announce` | 上任广播频道 |
| `skills` | 初始技能等级(精简船员模式) |
| `minimal_skills` | 初始技能等级(满员模式) |

`/datum/outfit`:
| 字段 | 说明 |
|---|---|
| `uniform` | 制服 |
| `suit` | 外套 |
| `belt` | 腰带 |
| `ears` | 耳机 |
| `glasses` | 眼镜 |
| `gloves` | 手套 |
| `shoes` | 鞋 |
| `mask` | 面具 |
| `head` | 头饰 |
| `backpack` | 背包 |
| `satchel` | 单肩包 |
| `duffelbag` | 行李袋 |
| `box` | 初始盒子 |
| `l_pocket`/`r_pocket` | 口袋 |
| `backpack_contents` | 包内物品 |
| `id` | ID卡类型 |
| `implants` | 植入物 |
| `strippable` | 可剥离模块 |
