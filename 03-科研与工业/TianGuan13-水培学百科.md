## 1. 水培箱基础

**代码**: `hydroponics.dm` — 基类 `/obj/machinery/hydroponics` (1,397 行)

### 1.1 水培箱类型

| 类型 | 代码路径 | 说明 |
|---|---|---|
| 标准水培箱 | `/obj/machinery/hydroponics/constructable` | 可建造的基本水培箱，含管道接口/USB口/钓鱼 |
| 豪华水培箱 | `/obj/machinery/hydroponics/constructable/fullupgrade` | 升级版，初始零件品质更高 |

### 1.2 水培箱状态变量

```
waterlevel  (0~100)         水位
reagents    (0~maxnutri)    营养液 (试剂容器)
maxwater    (默认100)       最大水量
maxnutri    (默认20)        最大营养量
pestlevel   (0~10)          害虫等级
weedlevel   (0~10)          杂草等级
toxic       (0~100)         毒素等级
plant_health                当前生命值 (上限 = seed.endurance)
plant_status                状态: 无植物/生长中/可收获/死亡
age                         当前年龄(周期数)
self_sustaining             自动维护模式(需供电)
light_level                 当前光照强度(0~1)
rating (1~3+)               零件品质评级，影响消耗速率
```

### 1.3 建造与升级

**电路板**: `/obj/item/circuitboard/machine/hydroponics`

零件升级影响:

| 零件槽 | 参数影响 |

| 总零件品质 | 耗电 = 初始值 / (总tier / 3)，高品质更省电 |

## 2. 种子系统

**代码**: `seeds.dm` — `/obj/item/seeds` (652 行)

### 2.1 核心属性

```
lifespan   (10~100，默认25)  寿命，超过后每周期掉血
endurance  (10~100，默认15)   生命值上限
maturation (默认6)           成熟所需周期
production (1~10，默认6)     每 X 周期可收获一次
yield      (0~10，默认3)     每次收获个数(-1=不可收获)
potency    (0~100，默认10)   效力，影响药剂量/产物大小/部分特殊效果
instability(0~100，默认5)    不稳定度，决定变异概率

weed_rate  (0~10，默认1)     每周期可能增加的杂草量
weed_chance(0~67%，默认5%)    增加杂草的概率

mutatelist                  可突变物种列表
genes                       基因列表 (试剂基因 + 特性基因)
reagents_add                试剂配方表
graft_gene                  接穗默认传递的基因
growthstages                生长阶段图标数 (默认6)
rarity                      稀有度 (货运定价)
```

### 2.2 收获产物公式

**产量**: `getYield()`
```
base = yield
if 非土壤 + soil_lover:   yield × 0.7 (SOIL_LOVER_HYDRO_YIELD_MALUS)
if yieldmod 存在:          yield × yieldmod
return round(result)
```

**产物尺寸**: `transform = transform × (potency/100 + 0.5)`

**试剂含量**: 每种试剂 = `max(1, round(100 × potency/100 × 配方倍率))`
- 产物标准容量 = **100u** (PLANT_REAGENT_VOLUME)
- 100 potency，倍率 0.2 = 20u 该试剂

**一口量**: `1 + round(max(potency × 0.05, 1) × (max_volume × 0.01) × bite_consumption_mod)`

### 2.3 种子复制
```
new_seed = new type(null, TRUE)  // nogenes = TRUE
复制所有 stats + genes + reagents_add
```

## 3. 生长周期

**代码**: `hydroponics.dm` — `process()` 方法

### 3.1 周期

- 1 周期 = `cycledelay` = **20 秒** (HYDROTRAY_CYCLE_DELAY)
- 每个周期: `age += 1`
- 蘑菇在 `FAST_MUSHROOMS` 土壤: `age += 1.4` (快 40%)

### 3.2 生长阶段流程

```
种植种子
    │ age=0
    ▼
[生长期] age < maturation
    │ 图标 = clamp(round(age/maturation × growthstages), 1, growthstages)
    ▼
[成熟期] age ≥ maturation
    │ 开始准备收获
    ▼
[可收获] age ≥ production 且 (age - lastproduce) ≥ production
    │ plant_status → HYDROTRAY_PLANT_HARVESTABLE
    ▼
[衰老期] age > lifespan
    │ 每周期 lose health = rand(1,5) / rating
    ▼
[死亡] plant_health ≤ 0 → plantdies()
    ├─ status → HYDROTRAY_PLANT_DEAD
    ├─ pestlevel = 0
    └─ weedlevel += 1
```

## 4. 水、营养与毒素

### 4.1 水循环

**耗水**: 每周期 `rand(1,6) / rating`
- `SUPERWATER` 水箱: 耗水 × 0.5

**缺水** (`waterlevel ≤ 10`):
- 非蘑菇: `lose health rand(0,1) / rating`
- 完全无水 (`≤ 0`): `lose health rand(0,2) / rating`

**水分充足** (`> 10` + 营养 > 0):
- `gain health rand(1,2) / rating`

**浇水稀释毒素**: `toxic -= 加入水量 / 4`

### 4.2 营养系统

**消耗**: `nutridrain = 1/rating`
- 正常: 每周期 `reagents.remove_all(nutridrain)`
- 自动维护: 每周期 `remove_all(min(0.5, nutridrain))`

**营养耗尽时**:
- 土壤有 `SLOW_RELEASE`: 自动生成 1u 氮
- 否则非杂草: `lose health rand(1,3)`

### 4.3 毒素

```
toxic ≥ 10:
  toxin_adaptation 基因 → 治疗 + 提升 potency
toxic ≥ 40 且无 tox_resistance:
  < 80: lose health -1/rating, toxic -= rating×2
  ≥ 80: lose health -3, toxic -= rating×3
```

毒素通过加水稀释: `每 +1 水 → -0.25 毒`

### 4.4 放射性暴露

当放射性试剂接触水培箱:

| 概率 | 效果 |
|---|---|
| 75% | `instability += 2×mod`，`toxic += 1.5×mod` |
| 41-50 | 植物掉血 -5×mod |
| 21-40 | 无效果 |
| 11-20 | 杂草突变 |
| 0-10 | 害虫突变 |

## 6. 病虫害与杂草

### 6.1 害虫阈值

```
pestlevel ≥ 8:
  非食肉: potency -= rand(2,6) (下限 CARNIVORY_POTENCY_MIN=30)
  食肉:   gain health 2/rating，pest -= 1/rating

pestlevel ≥ 4:
  非食肉: potency -= rand(1,4)
  食肉:   gain health 1/rating，50% pest -= 1/rating

pestlevel < 4 + 食肉:
  5% pest -= 1/rating
```

**自然发生**: 每周期 5% `pestlevel += 1`

**害虫突变** (`mutatepest()`): 如果 `pestlevel > 5` → 生成 3 只蜘蛛幼体

### 6.2 杂草阈值

```
weedlevel ≥ 5 + 非杂草植物:
  yield ≥ 3: yield -= rand(1,2) (下限 WEED_HARDY_YIELD_MIN=3)

weedlevel ≥ 10 + 非自动维护 + 50%:
  yield -= rand(1,2)
  无植物 → weedinvasion()
```

**杂草入侵** — 随机生成: 灵芝/荨麻/风铃草/毒蝇伞/鸡油菌/塔木/圆胖菇/星蓟

**杂草突变** (`mutateweed()`): 杂草值 > 5 时: 自由帽/毁灭天使/死荨麻/野葛

### 6.3 灭虫/除草工具

| 工具 | 效果 |
|---|---|
| 锄头 | 清除所有杂草 |
| 除草喷雾 | 100u Weedkiller |
| 杀虫喷雾 | 100u Pestkiller |

## 14. 蜜蜂养殖

**代码**: `beekeeping/` (5 文件)

蜜蜂在植物间传粉，提高产量。养蜂需要蜂箱、蜂框、熏烟器和防护服。

### 14.1 蜂箱（Apiary）

**代码**: `beekeeping/beebox.dm` (280 行)

| 常量 | 值 | 说明 |
|---|---|---|
| `BEEBOX_MAX_FRAMES` | 3 | 每箱最大蜂框数 |
| `BEES_RATIO` | 0.5 | 蜜蜂数 = 最大蜜巢数 × 0.5 |
| `BEE_PROB_NEW_BEE` | 20% | 蜜蜂资源转新蜜蜂的概率 |
| `BEE_RESOURCE_HONEYCOMB_COST` | 100 | 产一个新蜜巢消耗的蜂资源 |
| `BEE_RESOURCE_NEW_BEE_COST` | 50 | 产一只新蜜蜂消耗的蜂资源 |

**蜂箱机制**：
- 建造：木材×40（`custom_materials`），扳手可拆
- **蜂后**：蜂箱必须有一只蜂后（queen_bee）；用蜂后罐（queen_bee item）放入
- **蜜蜂资源（bee_resources）**：蜜蜂在箱外采蜜积累；每 tick 处理：
  - 有蜂后 + 资源 ≥100 且蜜巢未满 → 产新蜜巢（继承蜂后试剂类型）
  - 蜜蜂数不足 + (资源≥50 且 20%概率 或 无工蜂保底) → 产新工蜂（在箱外生成）
- **最大蜜巢** = 所有蜂框容量之和；**最大蜜蜂** = 最大蜜巢 × 0.5
- **试剂蜜蜂**：蜂后可携带试剂（beegent），产出的蜜巢/新蜜蜂继承试剂——**蜂蜜染色/风味系统**
- **换蜂后**：放入不同试剂蜂后 → 试剂不兼容的旧蜜蜂被驱逐（放飞）
- **交互**：
  - 无防护服（bee_friendly=false）→ 被蜜蜂攻击（工蜂全部飞出蜇人）
  - 有防护服（THICKMATERIAL 衣+帽 或 植物人）→ 可安全操作
  - 操作菜单：取蜂框（带走蜜巢）/ 放蜂后

### 14.2 蜂框与蜜巢

**代码**: `beekeeping/honey_frame.dm` + `honeycomb.dm`

- **蜂框（Honey Frame）**：蜂巢的骨架，有 `honeycomb_capacity`（承载蜜巢数）；放入蜂箱后蜜蜂在上面建蜜巢
- **蜜巢（Honeycomb）**：可食用的蜂蜜块，含蜂蜜/蜂后试剂；从蜂箱取出
- **采蜜**：拿蜂框右键蜂箱取出 → 蜜巢随框带出 → 收集蜂蜜

### 14.3 熏烟器与防护服

**代码**: `bee_smoker.dm` + `beekeeper_suit.dm`

- **熏烟器（Bee Smoker）**：可催眠蜜蜂！（hypnotize bees）
- **养蜂帽/养蜂服**：THICKMATERIAL 防护，防止被蜇；无防护直接操作蜂箱会被群蜂攻击

```

3. 保持充足水分(>10) 和营养(>0)
4. 蜜蜂传粉提高 yield 趋同(高 yield 植物带低 yield 的)
5. 基因改造提升 potency(产物更大+更多药剂)
6. 土壤喜好的植物(soil_lover)必须种在土壤中, 否则减半
```

### 8.4 稳定性管理

```
instability 控制:
  低 (<20): 稳定, 几乎不突变 — 适合保种
  中 (20-60): 属性突变但物种稳定
  高 (60-80): 可能变物种, 风险收益并存
  极高 (>80): 每周期都有可能变物种

降低 instability:
  - Robust Harvest 肥料
  - 杂交时选用 Safe Instability 基因
  - 自动维护模式 (auto-grow, 不触发物种突变)
```

### 8.5 快速纯种繁殖

```
1. 种一颗想要的种子
2. 用修枝剪取接穗
3. 准备好土(或蛭石土壤)
4. 接穗贴在空土上 → 繁殖出克隆植物
5. 重复, 大量扩增
```
