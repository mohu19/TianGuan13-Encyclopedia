# TianGuan13 给药途径对比百科 (Administration Routes Encyclopedia)

> 基于 TianGuan13 NovaSector 分支源码全量整理。核心：`code/modules/reagents/reagent_containers/`（patch/pill/syringes/hypospray/medigel）+ `code/modules/surgery/organs/internal/stomach/_stomach.dm`（口服吸收）+ `code/modules/reagents/chemistry/holder/`（代谢）。
> **范围**：贴片（patch）/ 药片（pill）/ 注射（inject）/ 涂胶（medigel）四种给药途径的完整数据与横向对比——**同一种药，用不同方式进入身体，起效速度和效果完全不同**。

## 概述

| 途径 | 容器 | 容量 | 进入方式 | 起效速度 |
|---|---|---|---|---|
| **贴片** | `/obj/item/reagent_containers/applicator/patch` | **40u** | PATCH 经皮 | 慢（0.75u/秒） |
| **药片** | `/obj/item/reagent_containers/applicator/pill` | **50u** | INGEST 口服→胃 | 中（胃滴灌） |
| **注射器** | `/obj/item/reagent_containers/syringe` | **15u** | INJECT 直接入血 | **最快（立即）** |
| **高压注射枪** | `/obj/item/reagent_containers/hypospray` | **30u** | INJECT 直接入血 | **最快（立即）** |
| **涂胶** | `/obj/item/reagent_containers/medigel` | **60u** | PATCH 经皮（10u/次喷涂） | 中（每次 10u 立即入体） |

## 一、贴片（Patch）—— 经皮吸收

**代码**: `code/modules/reagents/reagent_containers/patch.dm`

### 1.1 基础数据

| 属性 | 值 |
|---|---|
| 容量 | **40u**（`volume = 40`） |
| 涂抹时间 | **1.5 秒**（application_delay / self_delay） |
| 撕下时间 | **0.25 秒**（rip_time） |
| 吸收速率 | **0.75u/秒**（transfer_per_second） |
| 吸收方式 | PATCH（经皮，不经过胃） |
| 嵌入物 | `/datum/embedding/med_patch`（嵌入机制） |
| 部位要求 | 仅**有机肢体**（机械肢体不可贴） |
| 可燃 | FLAMMABLE（点燃会脱落销毁） |

### 1.2 吸收机制（process_effect）

- **每秒**转移 **0.75u** 给身体（`transfer_per_second`；SSprocessing 每 1 秒 fire 一次）
- **TRAIT_STASIS（冰冻/静止）持有者不吸收**
- 贴片耗尽（total_volume = 0）自动脱落销毁
- 消息冷却 10 秒（PATCH_MESSAGE_COOLDOWN，防刷屏）
- **瞬时版**（`med_patch/instant`）：一次性转移全部容量（如 synthflesh 贴片，效果只在首次涂抹时触发）

### 1.3 特殊贴片

| 贴片 | 内容 | 说明 |
|---|---|---|
| **libital 贴片（钝伤）** | libital 2 + Granibitaluri 8 | 止痛，轻微肝损伤 |
| **aiuri 贴片（灼伤）** | aiuri 2 + Granibitaluri 8 | 治疗灼伤，轻微眼损伤 |
| **无名贴片** | 芬太尼 2 | 无标签经皮贴片（反派用途） |
| **synthflesh 贴片** | synthflesh 20 | **瞬时版**；3 贴可复活烧伤干尸 |
| **ondansetron 贴片** | ondansetron 10 | 止恶心，可能嗜睡 |
| **化学大师定制** | 任意 | 可做任意药（见化学大师） |

> **直观理解**：贴片 = 慢速输液。40u 容量大，但 0.75u/秒 意味着贴满 40u 要 **53 秒** 才能全吸收——适合持续给药，不适合急救。

## 二、药片（Pill）—— 口服经胃

**代码**: `code/modules/reagents/reagent_containers/pill.dm`

### 2.1 基础数据

| 属性 | 值 |
|---|---|
| 容量 | **50u**（`volume = 50`） |
| 服用方式 | INGEST（口服） |
| 进入路径 | **进胃（stomach.reagents）** → 胃滴灌给身体 |
| 转移 | **实物进胃**（`stomach.consume_thing(src)`，涂层溶解后释放试剂）；无涂层/无胃时直接 `trans_to(INGEST)` |
| 化学大师涂层 | 默认 **3 层**（可 0-**30** 层；每层 = 1 秒胃内溶解延迟，涂层遮蔽味道） |

### 2.2 口服吸收机制（胃滴灌）

**代码**: `code/modules/surgery/organs/internal/stomach/_stomach.dm`

```
amount = min((0.05 × 存量 + max(试剂代谢率, 0.25)) × SPT, 存量)
```

- **胃转移效率**：`metabolism_efficiency = 0.05`（每 tick 转移 5% 存量）
- **最低速率**：`STOMACH_METABOLISM_CONSTANT = 0.25`（每 tick 至少转移 0.25u）
- 实际速率 = **5% 存量 + max(代谢率, 0.25)**，每 2 秒（SPT=2）
- **代谢率 ≤ 0 的试剂**（如塑料）永远留在胃里占空间
- **无胃**（被摘除）：口服直接呕吐（expel_ingested）
- 胃受损：低营养阈值时低概率呕吐，高损时高概率呕吐

### 2.3 药片类型

| 药片 | 内容 | 容量 |
|---|---|---|
| 毒素药片 | 毒素 50 | 50u |
| 氰化物药片 | 氰化物 50 | 50u |
| 吗啡药片 | 吗啡 30 | 30u |
| 太空霉素药片 | spaceacillin 1.5 | 1.5u |
| 兴奋剂药片 | 麻黄碱 10 + 解酒 10 + 咖啡 30 | 50u |
| 处方兴奋剂 | 糖 5 + 合那丁 5 + 莫达非尼 3 | 13u |
| 沙丁胺醇药片 | 沙丁胺醇 30 | 30u |
| 多效药片 | multiver 5 + granibitaluri 5 | 10u |
| **化学大师定制** | 任意（3 层糖衣） | ≤50u |

> **直观理解**：药片 = 口服缓释。50u 全进胃，然后按胃的速率滴灌——同一种药口服比注射慢得多，但容量大、适合长期服药。

## 三、注射（Injection）—— 直接入血

**代码**: `code/modules/reagents/reagent_containers/syringes.dm` + `hypospray.dm`

### 3.1 注射器（Syringe）

| 属性 | 值 |
|---|---|
| 容量 | **15u** |
| 单次转移 | 5 / 10 / 15u（可选） |
| 进入方式 | INJECT（直接入血液） |
| 特点 | 可抽血/抽液、可扎容器 |

### 3.2 高压注射枪（Hypospray）

| 属性 | 值 |
|---|---|
| 容量 | **30u**（特殊型号：CMO 版 60u / 战斗版 90u / nanites 100u） |
| 单次转移 | **5u** |
| 进入方式 | INJECT（直接入血液） |
| 特点 | 无针注射（不扎破）、不产生血迹、快速连发 |
| EMAG | 解锁战斗模式（延迟归零，见《医疗装备扩展百科》） |

### 3.3 注射的关键优势

- **绕过胃**：直接进身体试剂池（`target.reagents`），**不受胃的 5% 滴灌限制**
- **立即起效**：试剂按自身 `metabolization_rate` 代谢（默认 REAGENTS_METABOLISM = **0.2u/秒**）
- **可扎容器/机械**：注射器能对机器、药瓶等 `is_injectable` 目标用
- **战斗风险**：注射有刺入动作（3 秒 do_after），旁观可见；误吞注射器会注射 2/3 内容物 + **头部 5 点钝伤**

> **直观理解**：注射 = 直接入血。绕过胃的消化环节，效果立刻开始（按试剂自身代谢率），但容量小（15-30u），且需要目标可注射。

|---|---|
| 容量 | **60u** |
| 单次喷涂 | **10u** |

## 五、横向对比（核心）

### 5.1 同一种药（假设代谢率 0.2u/秒，50u）的起效对比

| 途径 | 容量 | 进入位置 | 吸收速率 | 50u 全吸收时间 | 起效速度 |
|---|---|---|---|---|---|
| **贴片** | 40u | 皮肤（PATCH） | 0.75u/秒 匀速 | ~53 秒（40u） | 慢但稳定 |
| **药片** | 50u | 胃→身体 | 5% 存量+0.25u/2秒 滴灌 | **~46 秒排空**（递减衰减） | 中（缓释） |
| **注射器** | 15u | 血液（INJECT） | 试剂自身代谢率 0.2u/秒 | 立即全部入血 | **最快** |
| **高压枪** | 30u | 血液（INJECT） | 试剂自身代谢率 | 立即全部入血 | **最快** |
| **涂胶** | 60u | 皮肤（PATCH） | 10u/次喷涂立即入体 | **6 次喷完**（每次生效） | 中（按次） |

### 5.2 关键差异点

| 维度 | 贴片 | 药片 | 注射 |
|---|---|---|---|
| **进入路径** | 经皮（不过胃） | 经胃（滴灌） | 直接入血 |
| **起效** | 慢（0.75u/秒） | 中（胃 5% 滴灌） | **立即** |
| **容量** | 40u | 50u | 15u（注射器）/ 30u（枪） |
| **持续给药** | ✅ 53 秒匀速 | ✅ ~46 秒递减缓释 | ❌ 一次性 |
| **可被移除** | ✅ 0.25 秒撕下 | ⚠️ 涂层期可催吐（60% 概率/件）；溶解后胃液可吐（10%+10u） | ❌ |
| **机械肢体** | ❌ 不可贴 | ✅ 可口服 | ✅ 可注射 |
| **TRAIT_STASIS** | ❌ 不吸收 | ✅ 胃仍转移？ | ✅ |
| **战斗隐蔽性** | 高（贴身上） | 中（吞服动作） | 低（刺入可见） |
| **过量风险** | 低（慢速） | 中（缓释） | **高（全量瞬间）** |
| **化学大师制造** | ✅ | ✅（3 层糖衣） | ❌（需装填） |

### 5.3 实战选型建议

| 场景 | 最佳途径 |
|---|---|
| **急救（失血/重伤）** | 高压枪或注射器——立即入血起效 |
| **长期服药（慢性治疗）** | 药片——50u 大容量缓释，不用反复打针 |
| **持续修复（烧伤/中毒缓慢治疗）** | 贴片——40u 匀速吸收 53 秒，贴完不管 |
| **隐蔽给药（下药/反派）** | 药片混入食物/饮料（INGEST 进胃）或贴片（无标签） |
| **大剂量（超 30u 单次）** | 贴片（40u）或药片（50u）——注射器/枪装不下 |
| **机械体（赛博格/义体）** | 注射（贴片不可贴机械肢体） |

### 5.4 机制核心（一句话）

> **贴片 = 皮肤恒速输液（0.75u/秒）；药片 = 胃滴灌缓释（5% 存量/2秒）；注射 = 瞬间全量入血（立即按代谢率生效）**——同药异途，起效天差地别。

## 六、特殊机制补充

### 6.1 胃的"留滞"效应

- **代谢率 ≤ 0 的试剂**（塑料等异物）永远留在胃里占空间，不吸收
- **胃受损**会触发呕吐（低营养阈值低概率 → 高损伤高概率）
- **无胃生物**（被摘除/异形）口服直接呕吐出来

### 6.2 化学大师制造（chem_master）

- **药片**：任意试剂组合，涂层**默认 3 层、可调 0-30 层**（PILL_MAX_PRINTABLE_LAYERS=30；每层=1 秒胃内溶解延迟，遮蔽味道）
- **贴片**：任意试剂组合，可选 19 种贴纸样式（brute/burn/toxin/oxygen/clown/monkey 等）

### 6.3 肝过滤差异

- **INJECT 直接入血的毒素**：立即面临肝过滤（liver_tolerance 检查）
- **INGEST 在胃里的毒素**：未入血前**不算体内含量**（肝检查会加胃内量）——所以口服毒药有"缓冲期"，可催吐抢救（催吐清胃液：10% 总量+每试剂≤10u+实物 60% 概率；无专门"洗胃"机制）
- **肝检查副作用**：肝检查把胃内量计入"总含量"会使身体内同种毒素更难被肝清除（amount 变大→超耐受→照常代谢）
