## 一、原理与定位

**蓝空间采矿机**（`/obj/machinery/bluespace_miner`）通过蓝空间力量，在**正确的温度与压力环境**下凭空生产矿石材料（"Through the power of bluespace, it is capable of producing materials."）。

**工作循环**（每 `processing_speed` 秒一次）:
```
① 检查环境（温度/压力/间距/供电/锚定/面板）→ 全部达标才继续
② 按加权表随机选一种矿石 → 生成 1 块板到机器脚下
③ 排出废热 CO₂（120°C，会污染环境！）→ 见第四节
```

**核心矛盾（务必先理解）**: 机器**要求环境 <20°C** 才能工作，但**每次产出都会排出 120°C 的 CO₂**——不通风的话机器会自己把自己热到停工。这是布置蓝空间采矿机最关键的工程问题，也是与普通矿机最大的区别。

## 二、建造

### 2.1 电路板获取（二选一）

| 方式 | 说明 |
|---|---|
| **工程补给**（推荐） | "Bluespace Miner Circuitboard Crate" 蓝空间采矿机电路板箱，**10,000 信用点**（`CARGO_CRATE_VALUE × 50`） |
| 拆解已有机器 | 撬棍拆解（crowbar）回收电路板 |

### 2.2 电路板制作需求（`req_components`）

| 组件 | 数量 |
|---|---|
| 玻璃板（glass） | 1 |
| **精炼蓝空间晶体**（`bluespace_crystal/refined`） | 1 |
| 物质箱（matter_bin） | 2 |
| 微激光（micro_laser） | 2 |
| 伺服（servo） | 2 |

### 2.3 精炼晶体怎么来（三步合成链，全仓唯一路径）

> ⚠️ **先区分两种晶体**：普通晶体板（焊接产物，`sheet` 型）≠ 精炼晶体（`refined` ore 型）。**电路板只收 refined**，别拿错。

```
① 挖矿获得蓝空间晶体矿石
   - lavaland / 小行星随机矿物（稀有度≈钻石，权重 1/77）
   - 或陨石掉落（meteor drop）
② 焊接（welder，消耗 50 单位燃料）→ 熔成蓝空间晶体板 sheet/bluespace_crystal（1 原矿 ≈ 1 板）
③ 分解：把板放【副手】，点击它（attack_hand）→ 转化为 1 个精炼晶体 refined
   （refined_type=null，不可再熔，专供电路板）
```

### 2.4 装配

- 机器需**锚定**（`needs_anchored = TRUE`）
- 供电：`idle_power_usage = 300W`（极低，一格 APC 即可）
- 面板关闭、未损坏

## 三、环境要求（能否工作的全部条件）

机器每次处理前检查 4 个环境错误标志（**任一非零即停工**，伴随蜂鸣声 + 对应图标；`update_mining_stat` 每 tick 刷新）：

| 标志 | 条件 | 含义 |
|---|---|---|
| `TOO_CLOSE` | 1 格范围（`range(1)`）内有**另一台**蓝空间采矿机 | 机器间距必须 >1 格 |
| `TOO_HOT` | 环境温度 **≥ 293.15K (20°C)** | **必须 <20°C**（严格低于室温！） |
| `LOW_PRESSURE` | 压力 **≤ 101.325 kPa** (1 atm) | 必须高于标准大气压 |
| `HIGH_PRESSURE` | 压力 **≥ 151.99 kPa** (1.5 atm) | 必须低于 1.5 倍标准压 |

**有效工作窗口**（全部满足才产出）:
- 温度：**< 20°C**
- 压力：**101.325 < P < 151.99 kPa**（1~1.5 atm 之间）
- 间距：与其他采矿机 **>1 格**
- 状态：锚定 + 有电 + 面板关闭 + 未损坏

> ⚠️ 判定是"≥ 即停"：温度**恰好 20°C**、压力**恰好 1 atm** 都会停工——必须留余量。
> `debug_mode = TRUE` 可跳过全部环境检查（仅管理员/测试用）。

## 四、废热问题（成败关键）

### 4.1 排放物

每次成功产出向所在格排放：
- **CO₂**：`MOLES_CELLSTANDARD` ≈ **104 mol**（标准格满量）
- **温度 393.15K (120°C)**：`T20C + gas_temp`（`gas_temp` 初始 100；微激光每级 -5K，**最低 373.15K/100°C**）

### 4.2 后果

排放的 120°C CO₂ 会**同时推高环境温度与压力**——正是机器自己的两个停工条件（≥20°C 或 ≥1.5atm）。**不处理废热，机器必然自停**（"atmos room with bluespace miners made me crazy" 这句代码注释说的就是废热地狱）。

### 4.3 通风方案（按推荐度）

| 方案 | 做法 | 评价 |
|---|---|---|
| **排风口直排太空/冷区** | 机器放气闸旁，CO₂ 直接排出站外 | ★★★ 最优：温度压力双解决，零维护 |
| **主动通风循环** | 上方接排风管 + 气泵，把热 CO₂ 抽走 | ★★★ 站内可用 |
| **冷库/冷藏室** | 放冷库内（<20°C 环境） | ★★ 需持续保持低温，注意 CO₂ 累积 |
| **自由空间大房间** | 放超大房间稀释热 CO₂ | ★ 治标不治本，迟早超限 |

### 4.4 升级缓解（RefreshParts）

| 部件 | 效果 |
|---|---|
| 微激光（micro_laser） | 每级 **-5K** 废气温度（100K → 最低 80K，即排放温度 393→373K） |
| 伺服（servo） | 每级 **-0.5 秒** 处理周期（6s → 最低 4s） |

> 微激光升级只缓解温度，**不解决压力累积**——通风仍是刚需。

## 五、产出机制

### 5.1 产出表（`ore_chance` 加权随机，每周期 1 块板落地机器脚下）

| 矿石 | 权重 | 概率（77 总权重） | 备注 |
|---|---|---|---|
| 铁（iron） | 20 | 26.0% | 最常出 |
| 玻璃（glass） | 20 | 26.0% | 与铁并列最高 |
| 等离子（plasma） | 14 | 18.2% | 燃料来源 |
| 银（silver） | 8 | 10.4% | |
| 钛（titanium） | 8 | 10.4% | |
| 铀（uranium） | 3 | 3.9% | |
| 金（gold） | 3 | 3.9% | |
| 钻石（diamond） | 1 | 1.3% | 最稀有 |
| （EMAG 后）香蕉矿 bananium | +1 | ~1.3% | 见第六节 |

> 产出物是**矿石板（sheet）**，直接 `new chosen_sheet(get_turf(src))` **落地生成在机器脚下**——注意：模块 readme 宣称"产出到连接的矿石硅仓（ore silo）"，**但代码实际无硅仓对接**，以落地为准。

### 5.2 聚焦机制（set_focus）★

点击机器 → 选择一种矿石聚焦 → 该矿石权重 **×3**；再点取消（÷3 还原）。

- 聚焦后选中**其他**矿石时本次**直接跳过不产出**（`focused_item != chosen_sheet → return`）
- 即聚焦 = "提高目标出现率 + 放弃非目标产出"，非目标周期全部空转
- **例**：聚焦铁（20→60，总权重 77+40=117）→ 每周期 51% 出铁、49% 空转；**不聚焦则每周期 100% 出 1 块（随机）**

### 5.3 周期

默认 **6 秒**一次，伺服升级最多降到 **4 秒**。

## 七、实战布置建议

```
最佳布置（站内）:
┌──────────────┐
│  排风口/气闸   │ ← CO₂ 直排太空
│      ↑        │
│  [蓝空间采矿机] │  温度<20°C 压力1~1.5atm
│  脚下←矿石堆积  │  间距>1格(远离其他采矿机)
└──────────────┘
```

1. **首选**：放气闸/太空墙边，让 120°C CO₂ 自然排出站外——温度压力同时解决，零维护；
2. **站内方案**：上方排风管 + 气泵抽走热 CO₂；或放冷库；
3. **多台并行**：每台间隔 ≥2 格（1 格内不能有另一台），否则 TOO_CLOSE 停工；
4. **产出收集**：矿石直接落机器脚下，可接传送带/矿车/人工捡；
5. **供电**：300W 极低，普通 APC 即可；
6. **用途**：铁/玻璃无限自给（建造耗材）、等离子供燃料、钻石/金/铀换钱或科研——一台机器即可支撑工程部日常消耗。

## 八、故障排查

| 症状 | 原因 |
|---|---|
| 蜂鸣 + TOO HOT 图标 | 环境 ≥20°C——废热累积或放太热了，通风/冷却 |
| 蜂鸣 + PRESSURE LOW 图标 | 压力 ≤1atm——所在格漏气/真空/太空，加压或挪位置 |
| 蜂鸣 + PRESSURE HIGH 图标 | 压力 ≥1.5atm——CO₂ 排不出去堆压，排风 |
| 蜂鸣 + PROXIMITY 图标 | 1 格内有另一台采矿机，移开 |
| 完全不工作无图标 | 没电/未锚定/面板打开/损坏 |
| 出矿变慢/空转 | 聚焦了某种矿石（非目标周期跳过）——取消聚焦恢复全随机 |
| 电路板做不出来 | 缺精炼晶体（refined）——普通晶体板不对，按 2.3 三步合成 |
