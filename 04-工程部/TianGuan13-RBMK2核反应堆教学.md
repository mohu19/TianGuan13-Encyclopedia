## 一、原理与定位

**RB-MK2 反应堆**（`/obj/machinery/power/rbmk2`）是 NOVA 的**高仿真核反应堆**——用"蓝空间魔法直接把氚粒子转化为能量，发热极小"的先进发电技术（"uses bluespace magic to directly convert tritium particles into energy with minimal heat generation"）。

**核心特征**：
- 平台形机器（`density = FALSE`，**可以站人**），需锚定，防火
- **功率与温度正相关**：棒越热，产电越高（温度因子 `(1+(T-273)/1500)^1.4`）
- **事故链完整**：过热 → 安全系统介入 → 熔毁 → 电离化 → 临界值 → **临界爆炸**（毁天灭地级）
- 电站本体部署在 Blueshift 地图（47 个反应室格 + 6 根随机氚棒 + 1 台探测器）

**工作循环**（每 2 秒一次，SSmachines）:
```
① 从棒内抽氚（耗量 = 基础 + 温度×热耗，×压力修正 0.25~1）
② 产电 = 耗氚 × 效率 × 7,800,000 × 温度因子 × 压力因子（超频 ×0.9）
③ 50% 氚被删除，其余进废气缓冲
④ 生成"地精气"×8（神秘废气，接触有害）
⑤ 温度飙升（超功率上限时 ×4 倍率）
⑥ 缓冲气与棒互换温度（冷却限制器生效）
⑦ 检查安全系统 / 熔毁条件
```

## 五、功率公式全解析

### 5.1 氚消耗（每周期 = 2 秒）

```dm
amount_to_consume = (0.000005 + (棒温/1000)×0.0018)          // 基础 + 温度热耗
                 × clamp(1 - (棒压-4500)/4500, 0.25, 1)      // 压力修正 0.25~1（压力越高耗越少）
                 × (超频 ? 1.25 : 1)                          // 超频 ×1.25
                 × (0.75 + 效率×0.25)                         // 效率因子
                 × (emag ? 10 : 1)                            // emag 过载 ×10
```

### 5.2 产电

```dm
power = 耗氚 × 效率 × 7,800,000 × (超频 ? 0.9 : 1)           // 基础产电（超频耗多产少）
      × (1 + max(0,(棒温-273.15)/1500))^1.4                  // 温度因子（越热越高）
      × (0.75 + 耗量/基础×0.25)                               // 消耗因子
入网: add_avail(min(power, max_power_generation×10))          // 单周期封顶 max×10
```

### 5.3 关键数值

| 项 | 值 | 说明 |
|---|---|---|
| 基础产电 | **7,800,000 J/mol 氚** | 每 mol 氚的发电量 |
| 基础耗氚 | 0.000005 mol/周期 | 常温基础 |
| 温度耗氚 | +0.0018 mol/1000K | 越热耗越多 |
| 安全功率上限 | **230,000 J** | 超过触发安全系统（物质箱提升） |
| 最大功率 | **350,000 J**（物质箱提升） | 绝对上限 = 其 20 倍（7,000,000） |
| 功率效率 | 1（电容器提升） | 影响产电与产热 |
| 排气压力 | 200 kPa（伺服提升） | 通风速率 |

> ⚠️ **功率-温度正反馈陷阱**：产电越高 → 温度升越高 → 温度因子越大 → 产电再涨 → 恶性循环。功率超 max 时温度增速 ×4。**必须靠冷却限制器与通风压制**，否则必然触发熔毁条件。

## 六、冷却与通风

### 6.1 废气缓冲（buffer_gases）

- 每次运行：50% 耗氚被删除，其余 + **地精气 ×8**（`/datum/gas/goblin`，神秘废气，接触有害——氚尽后应立即处理棒）进缓冲
- 缓冲气与棒**互换温度**（`transfer_rod_temperature`），冷却限制器生效

### 6.2 通风系统（venting）

| 状态 | 行为 |
|---|---|
| 通风开 + 正方向（默认） | 缓冲气以 `vent_pressure` 泵入环境（运行中减半速率） |
| 通风开 + 反方向 | **从环境吸冷气入缓冲**（实现常温运行——但会吸走房间空气！） |
| 通风关 | 停止内外交换（紧急手段） |

### 6.3 冷却限制器（cooling_limiter）

- 默认 50%，上限 90%（`cooling_limiter_max`）
- 作用：棒向环境传热时，冷却量 ×`(1 - limiter×0.01)`——**限制器越高，冷却越慢，棒越热，功率越高（也更危险）**
- 电线 LIGHT 脉冲 +10%（循环 0→90%）；剪线 = 归零（全速冷却）；接回 = 复位 50%

> **冷却方案**：通风正方向直排太空/大气循环 + 冷却限制器调低（安全）或调高（压榨功率）。指南明确"**必须先开循环**再激活"。

## 七、安全系统与事故链

### 7.1 安全系统（safety）

触发条件：`功率 ≥ 安全上限 230,000` **或** `棒压 > 限压 90%`（8,100 kPa）
```
卡棒概率 = 80 - 健康%×100 - (未通风 ? 40 : 0)
若卡棒成功 → 强制卡棒（jam）
否则 → 强制停机 + 3 点伤害 + 震动
```
- 判定概率 ×0.5/周期。"Nanotrasen 想让员工有安全感。"

### 7.2 熔毁（meltdown）

**触发条件**: 棒温 > 2073.15K **或** 产电 > max×(1.1+rand)

**熔毁中**:
- 播放随机熔毁警报（failure01-04.ogg），持续自伤（2/周期），图标切 5 帧熔毁循环
- **无法取出燃料棒**，激活键只能卡棒
- 持续**电离化周围空气**：范围 0.5+温/2000 格（上限 5）；80% 概率把 25% 氧转成氚
- **临界值 criticality 持续上升**（每周期 +0.01~3，按电离比例）
- 电离声循环（ionization.ogg）

**临界爆炸**（criticality ≥ 100 后继续涨）:
```
每 tick 有 (criticality/500) 概率直接爆炸:
  威力 = 临界/100 × 8（dev 0.25× / heavy 0.5× / light 1× / flash 2×）
  + 4 倍最大辐射脉冲（阈值 RAD_FULL_INSULATION——满防护也挡不住）
```

**退出熔毁极难**: 需温度 ≤ 限压 75%（1554K）**且** 功率 ≤ max 的 50%——双条件满足才自动解除。

### 7.3 卡棒（jam）

| 项 | 说明 |
|---|---|
| 触发 | 安全系统 / 爆炸（ex_act 强制卡棒） |
| 后果 | 无法开关机、取棒、扳手 |
| 解卡① 撬棍/活塞 | 4 秒用力撬，**扣 25-50 耐久**（`force_unjam` 默认 50，撬棍/活塞 25） |
| 解卡② 强制弹射 | UI 连按弹射：80% 概率损坏机+棒（各 0.5 伤害）、20% 直接解锁并停机 |
| 解卡③ 脉冲线 | Throw 线反复脉冲可解卡（指南彩蛋） |
| 最糟 | 熔毁中卡住 = 无法降温也无法取棒 → 等临界爆炸 |

### 7.4 摧毁爆炸（on_deconstruction）

- 被摧毁（非拆解）时若有棒：**临界 > 0 → 棒爆 + 爆炸**（威力 = 临界/100×8）+ 4 倍最大辐射脉冲；临界 = 0 → 普通爆炸
- 拆除/破坏必查棒！

### 7.5 EMP / EMAG

**EMP 连锁**（初始 50% 概率，每成功一项 -10%）：开关 → 通风 → 弹射（50% 抛飞）→ 超频随机 → 冷却限制随机 → 安全随机

**emag 过载**: 强制关安全 + 耗氚 ×10 + 全站公告"超速运转"——**emag 后的反应堆是移动的切尔诺贝利**。

### 7.6 互斥

同格放两台反应堆 → 开启时**自动解体对方**（防叠放）。

## 十、故障排查与禁忌

| 症状 | 原因/处理 |
|---|---|
| 激活无反应 | 无棒 / 未锚定 / 卡住 |
| 产电为 0 | 棒里没氚（消耗完自动停机） |
| 功率上不去 | 棒温低（温度因子小）——提高温度/限制器 |
| 安全系统狂介入 | 功率超 230,000 或棒压超 8,100——降功率或降压 |
| 熔毁警报响 | **立即**：切通风、降冷却限制、弹射棒（若未卡）、全站撤离 |
| 棒取不出来 | 卡住了——撬棍/活塞 4s（扣耐久），或连按弹射碰 20% |
| 临界值狂涨 | 熔毁中电离化——想办法降温（<1554K + 功率<50%max）或等爆炸 |
| 无棒却显示 closed | 棒被毁弹出——机器自动停机（atom_destruction 处理） |

**绝对禁忌**:
1. **不装 TTV**（代码专门拦截，棒会炸）
2. **同格叠两台**（自动解体）
3. **先开机再开冷却**（指南原话：冷却必须先开）
4. **剪 Safety 线还开机**（永久关安全，熔毁预定）
5. **emag 过载后不撤离**（耗氚 ×10，温度失控）
6. **熔毁中撬棒**（根本取不出，只会浪费时间）
