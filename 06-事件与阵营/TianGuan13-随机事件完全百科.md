# 第一卷 · 事件系统机制

## 1.1 调度核心（SSevents 子系统）

**代码**: `code/controllers/subsystem/events.dm`

| 机制 | 值 |
|---|---|
| **触发频率** | 每 **2.5-7 分钟**随机（frequency_lower/upper，config 可调） |
| **选择方式** | 权重 pick_weight（weight 越高越可能） |
| 玩家门槛 | 活人非 AFK 人类数（get_active_player_count） |
| 权重 <0 | **开场事件**（回合开始触发） |
| 配置文件 | config/events.json（+ NOVA 的 nova/events.json） |
| wizardmode | 开关决定巫师事件入池 |
| 地图旗标 | EVENT_PLANETARY_ONLY（仅行星地图） |

## 1.2 事件控制判定链（can_spawn_event）

| 条件 | 说明 |
|---|---|
| occurrences < max_occurrences | 出现次数未达上限 |
| earliest_start 已过 | 回合最短时间 |
| wizardevent == wizardmode | 巫师模式匹配 |
| players_amt ≥ min_players | 玩家数门槛 |
| holidayID 匹配 | 节日专属事件 |
| 未紧急撤离 | EMERGENCY_ESCAPED_OR_ENDGAMED 禁 |
| ghost_role 旗标 | 幽灵角色事件需 GHOSTROLE_MIDROUND_EVENT |

## 1.3 事件生命周期

```
setup() → start() → announce() → tick()（多次）→ end() → kill()
```

| 阶段 | 触发时机 |
|---|---|
| start_when | 事件开始（秒） |
| announce_when | 公告（秒）；announce_chance 概率（默认 100） |
| end_when | 事件结束（秒） |
| fakeable | 可被假新闻事件伪装 |
| announce_deadchat | 死亡频道通知（follow 链接） |

## 1.4 NOVA 修改

①**管理干预通知**：触发前两次通知+提示音（server-ready.ogg）（原版一次无音效）②nova/events.json 独立配置 ③I18N 全文件。
