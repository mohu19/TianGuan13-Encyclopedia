## 一、核心概念

**太空海盗**（`/datum/antagonist/pirate`）是经典海盗题材反派：整队海盗乘穿梭机突袭空间站，掠夺物资、绑架人质勒索、偷取数据。

**核心设计**：
- **团队制**：所有海盗同属 `Pirate crew` 团队，共享目标
- **帮派系统**：10 个风格迥异的帮派（普通/骷髅/蜥蜴/国税局/中世纪等），各有装备与背景
- **穿梭机+数据虹吸**：海盗穿梭机配 Data Siphon（偷数据+锁货运）
- **战利品出口**：货舱垫+控制台，把抢来的东西卖出换钱（含人质赎金）
- **幽灵报名**：mob_spawn 幽灵角色（海盗休眠舱）

## 三、海盗穿梭机与装备

### 3.1 穿梭机设备

| 设备 | 说明 |
|---|---|
| **海盗穿梭机**（docking_port/mobile/pirate）| 海盗专用船 |
| **穿梭机控制台**（shuttle/pirate）| 开船 |
| **导航电脑**（shuttle_docker/syndicate/pirate）| 指定停靠点 |
| **投递舱**（drop_pod）| 空降攻击舱 |
| **宇航服储物柜**（suit_storage_unit/pirate）| EVA 装备 |

### 3.2 数据虹吸机（Data Siphon / shuttle_scrambler）

**海盗核心装备**：
- **偷取信用点和数据**：从不受保护的系统偷钱/数据
- **锁定货运穿梭机**：锁住空间站的货运船
- **打断科研**（interrupt_research）：干扰研究进度
- **倾倒战利品**（dump_loot）：把偷的数据转出货舱
- 通知功能（send_notification）：行动提示

### 3.3 战利品定位器（Booty Locator / loot_locator）

- 扫描附近空间的**贵重物品**（find_random_loot）——海盗版矿脉扫描仪

### 3.4 货舱垫与控制台（piratepad + piratepad_control）

- 货舱传送垫：把战利品传送到指定点
- 控制台：`send` 发送战利品、`pirate_export_loop` 循环出口、`recalc` 计算价值

## 四、战利品系统（出口/赎金）

### 4.1 出口（datum/export/pirate）

| 出口物 | 价格 | 说明 |
|---|---|---|
| **人质赎金** ransom | **3,000 起** | 绑架船员当人质卖（get_cost 按人质价值），卖出后送回空间站 |
| **活鹦鹉** parrot | 2,000 | 活的鹦鹉（海盗梗）|
| **现金** cash | 1/张 | 空间现金 |
| **全息币** holochip | 1/个 | 全息币 |

### 4.2 战利品目标（objective/loot）

```
"Acquire loot and store [target_value] of [货币] worth in [货舱区] cargo hold."
（获取并囤积指定价值的战利品到货舱）
```

- 目标价值：team 生成时随机（forge_objectives）
- 判定：货舱内物品总价值 ≥ 目标值（get_loot_value 计算）

## 六、对战攻略

### 怎么玩海盗（推荐流程）

```
① 出生海盗穿梭机 → 穿装备（EVA 或普通）→ 导航靠站/投递舱空降
② 优先放 Data Siphon（偷钱偷数据+锁货运）
③ 突袭目标：银行机/仓库/贵重物资区
④ 抓人质 → 货舱垫送走 → 卖赎金（3,000+/人）
⑤ 用 Booty Locator 找稀有战利品
⑥ 目标价值凑满 → 撤离（穿梭机）
```

### 怎么防海盗（船员对策）

| 方法 | 说明 |
|---|---|
| **盯穿梭机** | 海盗船停靠/空降有提示——提前布防 |
| **护银行机** | 数据虹吸偷钱——断电或护住银行系统 |
| **人质保护** | 落单船员是绑架目标——结伴行动 |
| **反制数据虹吸** | 发现后反击虹吸机（可摧毁）|
| **货运锁定应对** | 货运被锁=海盗已布置——沿货运路线搜索 |
