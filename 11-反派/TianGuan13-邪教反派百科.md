## 五、Nar'Sie 召唤机制

**Nar'Sie 本体**（`narsie.dm` 336 行）——邪教的终极目标：

**召唤条件**:
- 3 个**弱界点**（weak points）各放 Nar'Sie 召唤符文
- 每处需 **9 教徒**咏唱 + **50 秒**引导 + 施法者持续 **40.1 自伤**

**Nar'Sie 效果**:
- 古神降临 → 吞噬空间站（类似超物质事件）
- 信徒比 >Risen（20%）红眼发光 / >Ascendent（40%）全光环

**胜利判定**:
- 召唤成功 = 邪教大捷（Nar'Sie 毁灭全站）

## 九、对战攻略

### 怎么玩邪教（推荐流程）

```
① 开局：仪式匕首+10 符文金属 → 画 Offer 符文
② 转化：抓落单船员 → Offer 转化（2 教徒）→ 滚雪球
③ 建结构：神龛/熔炉/档案（符文金属需求）
④ 血魔法：召唤武器 → 武装教徒
⑤ 献祭 3 次 → 解锁复活符文 → 不怕损失
⑥ 构造体：铁 50 → 壳 → 灵魂石 → Juggernaut 推线
⑦ 终极目标：3 弱界点召唤 Nar'Sie
```

### 怎么防邪教（船员对策）

| 方法 | 说明 |
|---|---|
| **盯符文** | 看到地上的符文立刻破坏——邪教命脉 |
| **拆结构** | 神龛/熔炉/祭坛是邪教基建——优先拆 |
| **别落单** | Offer 转化专抓落单——结伴行动 |
| **灵魂石警惕** | 队友突然失踪=可能被抓去献祭 |
| **反召唤** | 看到 9 人咏唱=召唤 Nar'Sie——立即打断（50s 引导）|
| **血魔法反制** | 教徒受伤=血魔法燃料——压制血量 |
