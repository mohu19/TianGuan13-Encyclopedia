## 一、核心概念

**太空龙**（`/datum/antagonist/space_dragon`）是召唤流反派：本体不算特别强，但能**召唤裂隙**源源不断产出太空鲤（carp）——时间拖得越久，增援越多，最终用**鲤群海**淹没空间站。

**核心设计**：
- **裂隙系统**：在特定区域放置裂隙 → 裂隙充能 → 召唤太空鲤
- **Wavespeak**：龙↔太空鲤之间的心灵链接网络（聊天颜色 #635BAF）
- **目标**：裂隙充能完成（maxRiftTimer = 300）
- **5 个候选裂隙区**：随机选择站内合法区域

**Antag 属性**（space_dragon.dm datum）:

|---|---|
| roundend_category | "space dragons" |
| pref_flag | ROLE_SPACE_DRAGON |
| 阵营 | FACTION_CARP（太空鲤阵营）|

**基础属性**:

## 二、太空龙本体

**太空龙**（space_dragon antag）:
- 本体是一条**大型太空龙**（太空鲤的龙王）
- 获得阵营：FACTION_CARP（与鲤群友好）
- 出生自带 2 能力：召唤裂隙 + 定位裂隙
- 死亡 → 裂隙全毁（destroy_rifts 信号）
- 每 tick 检查裂隙状态（rift_checks）

**死亡惩罚**：太空龙死亡 = 所有裂隙销毁 = 增援停止。**龙是核心，保护自己就是保护裂隙**。

## 三、裂隙系统（核心机制）

### 3.1 召唤裂隙（Summon Rift）

- 能力：`summon_rift`（innate 行动）
- 在当前区域召唤裂隙（carp_rift）
- 限制：裂隙只能放在**合法区域**（见下）

### 3.2 裂隙位置选择

```
forge_objectives:
① 收集所有合法区域（过滤室外/非法领土）
② 随机选 5 个区域（pick_n_take）
③ 作为裂隙候选（chosen_rift_areas）
```

**合法区域条件**：非室外（outdoors）+ VALID_TERRITORY 标志——**只能在站内合法领土放裂隙**。

### 3.3 裂隙充能

- `riftTimer`：裂隙计时器（0→300）
- `maxRiftTimer = 300`：充能完成目标
- `rifts_charged`：已充能裂隙数
- 充能完成 → 目标完成

### 3.4 裂隙功能

- 裂隙是**太空鲤传送门**：从裂隙召唤鲤群
- 裂隙可被破坏（需要龙保护）
- 龙死亡 → 裂隙全部销毁

### 4.1 增援类型

| 类型 | 说明 |
|---|---|
| **精英鲤**（advanced carp）| minion_to_spawn——裂隙召唤的主力增援 |

### 4.2 太空鲤反派（datum/antagonist/space_carp）

被裂隙召唤的太空鲤也是**玩家反派**（幽灵可报名）：
- 目标："Protect the rift to summon more carps."（保护裂隙以召唤更多鲤）
- 每个 space_carp 绑定自己的裂隙（rift）
- 加入龙的心灵链接网络（Wavespeak）

## 五、Wavespeak 心灵链接

- 组件：`mind_linker`（network_name = "Wavespeak"）
- 聊天颜色：#635BAF
- 链接对象：太空龙 + 所有召唤的太空鲤
- 功能：龙和鲤群**团队语音**（跨阵营沟通）
- 死亡信号：COMSIG_LIVING_DEATH 断开链接
- 语音图标：actions_space_dragon.dmi（wavespeak 图标）

**战术意义**：龙可以精确指挥每条鲤——"去东边""守住裂隙""集火某人"。

## 七、对战攻略

### 怎么玩太空龙（推荐流程）

```
① 出生 → 查看 5 个候选裂隙区
② 选防守严密的区域放第一个裂隙（越安全越持久）
③ 召唤精英鲤 → 守裂隙（鲤群自动增援）
④ 用 Wavespeak 指挥鲤群骚扰/进攻
⑤ 裂隙充能推进（300 计时）
⑥ 目标完成 → 或拖到全站沦陷
```

### 怎么防太空龙（船员对策）

| 方法 | 说明 |
|---|---|
| **优先杀龙** | 龙死=裂隙全毁=增援停止（最有效）|
| **拆裂隙** | 裂隙可被破坏——发现即摧毁 |
| **防推进** | 裂隙只能在合法区域——重点防守那 5 个候选区 |
| **别被鲤群耗** | 太空鲤海战术——用范围武器/穿甲清理 |
| **盯 Wavespeak** | 鲤群有组织行动=龙在指挥——找龙 |
