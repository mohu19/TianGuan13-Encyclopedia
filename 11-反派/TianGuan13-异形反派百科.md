## 一、核心概念

**异形**（`/mob/living/carbon/alien`）是经典异形（Alien）题材反派：以**寄生繁殖**为核心——抱脸虫感染人类 → 胚胎在体内生长 → 破胸而出幼虫 → 幼虫成长进化为各职阶成体 → 皇后产卵扩张蜂巢。

**核心设计**：
- **等离子（Plasma）能量系统**：所有能力消耗等离子（身体器官 `plasmavessel` 储存），战斗中自动恢复
- **进化树**：幼虫(25HP) → 成体 4 职阶（战士/哨兵/无人机/守卫）+ 2 皇家（禁卫/皇后）
- **感染链完整**：皇后产卵 → 抱脸虫附脸 → 胚胎 6 阶段 → 破胸幼虫
- **抗性全面**：无法被手铐、免疫浩克重击、免疫注射（皇后级）
- **法律豁免**：beepsky 不猎杀异形（assess_threat 返回 FALSE）

**基础属性**（成体通用）:
| 项 | 值 |
|---|---|
| 近战 | 20 伤（徒手） |
| 手铐 | **canBeHandcuffed 返回 FALSE——无法上铐** |
| 挣脱 | 自定义 cuff_resist / resist_grab |
| 酸免疫 | 自带酸液免疫（can_touch_acid） |
| 威胁评估 | beepsky 不追猎（assess_threat 假） |
| 睡眠 | 可睡觉（mob_sleep verb）|
| 捡球 | 可玩篮球（无法被缴械，游戏外之理） |

## 二、感染链（抱脸虫→胚胎→幼虫）

### 2.1 抱脸虫 Facehugger（`/obj/item/clothing/mask/facehugger`）

| 项 | 值 |
|---|---|
| 类型 | 面具（mask 槽位）——**戴脸上** |
| 耐久 | 100 |
| 活性 | 靠近目标自动激活（HasProximity）|
| 弹跳 | 可投掷/扑向目标（leap_to）|
| 附着 | 需目标**无面具/面罩防护**（CanHug 检查）|
| 挣脱 | knockoff 组件：**40% 概率被打掉**（头部/胸部）|
| 邮件 | 可通过叛徒邮件系统投递（on_mail_unwrap）|

**附着流程**：投掷/扑向目标 → 附着在脸上（mask 槽）→ 尾针刺入 → **植入胚胎**（impregnate_target）→ 完成使命后死亡（die）。

**特殊变体**:
| 变体 | 说明 |
|---|---|
| **Lamarr**（lamarr）| 著名抱脸虫宠物（剧情彩蛋） |
| dead 死体 | 已死亡（不可植入） |
| impregnated 已植入 | 已完成植入 |
| **toy 玩具** | 恶作剧玩具（采矿营地整人用），短暂附着后重新充电 |

### 2.2 胚胎 Alien Embryo（`/obj/item/organ/body_egg/alien_embryo`）

**6 阶段生长**，每阶段 60 秒（`growth_time = 60 SECONDS`），总约 **5 分钟破胸**：

| 阶段 | 宿主症状 |
|---|---|
| 1-2 | 无症状（潜伏） |
| 3-4 | 打喷嚏/咳嗽（1% 概率/tick）+ 危险预感提示 |
| 5 | 频繁喷嚏咳嗽 + **胸痛（2% 概率，20% 造成 1 伤）+ 中毒感（2%，20% +1 毒）** |
| 6 | **剧烈疼痛提示 + 持续毒伤（5/s）** → 破胸 |

**生长速度修正**:
| 状态 | 倍率 |
|---|---|
| 太空霉素（VIRUS_RESISTANCE）| **×2（慢一倍）** |
| 巢穴束缚（nest_sustenance）| ×0.80（**快 20%**——被粘在巢里加速生长）|
| 免疫缺陷（IMMUNODEFICIENCY）| ×0.5（**快一倍**——糟糕免疫系统）|

**破胸（attempt_grow）**:
- 第 6 阶段后 50% 概率/检查尝试破胸
- **投票招幽灵**扮演幼虫（poll 20 秒，ROLE_ALIEN 角色，可被 jobban 拦截）
- 无幽灵报名 → 生长倒退 1 分钟（stage 回 5，稍后再试）
- 成功：宿主胸部受 **150 BRUTE 伤**（致命一击）+ 幼虫破体而出
- **手术豁免**：若宿主胸部手术中（皮开/锯骨），不 gib（给手术取胚留机会）
- 宿主感染后医疗扫描可见 "Stage: X/6"（SCANPOWER_SUPER 级扫描仪）

### 2.3 幼虫 Larva（`/mob/living/carbon/alien/larva`）

| 项 | 值 |
|---|---|
| HP | **25** |
| 近战 | 1-3 伤（几乎无战力） |
| 等离子舱 | 小型/微型（tiny） |
| 成长 | `amount_grown` 0→100（每 tick +1，成长满后可进化） |

**策略定位**：破胸后最脆弱的阶段——**立刻找通风管/阴暗处隐藏**，等 amount_grown 满 100 后进化为成体。

## 四、能力系统（等离子+行动全录）

### 4.1 等离子能量（Plasma）

- 储存在器官 `plasmavessel`（按职阶大小不同）
- 能力消耗等离子（名称后缀显示 `(XP)`，如 "Corrode (200P)"）
- 通过 `adjustPlasma()` 自然恢复；幼虫的等离子消耗转为成长值

### 4.2 能力行动全录（datum/action/cooldown/alien）

| 能力 | 等离子消耗 | 效果 |
|---|---|---|
| **Plant Weeds 铺草** | 50 | 铺设异形草（巢穴地基/移动加速） |
| **Whisper 虫语** | 10 | 异形间心灵交流 |
| **Transfer Plasma 传递等离子** | 0 | 把等离子给其他异形（团队资源池） |
| **Corrode 腐蚀** | 200 | 点击目标喷射强酸（**腐蚀地板/门/墙**，开路神技） |
| **Spit Neurotoxin 喷神经毒素** | 50 | 远程喷毒，**大量耐力伤害**（击晕效果，电击枪手感） |
| **Resin 树脂** | 55 | 建造树脂结构（巢穴防御） |
| **Regurgitate 反刍** | — | 吐出胃中物（被抓后逃跑：**扇形吐出 9 格内胃容物**） |
| **Sneak 潜行** | — | 异形潜行（mob_cooldown/sneak/alien） |
| **Evolve 进化** | 500 | 无人机→禁卫 / 禁卫→皇后 |
| **Lay Egg 产卵**（皇后） | 75 | 产异形卵 |
| **Promote 晋升**（皇后） | 500 | 晋升其他异形 |

**酸液腐蚀细节**（corrosion）：
- 点击模式（set_click_ability）——选定目标后喷射
- 200 等离子/次，可腐蚀：地板、门、墙体——**异形不需要撬棍，酸就是万能钥匙**

**神经毒素细节**：
- 点击模式，弹道飞行（不追踪但命中即生效）
- 50 等离子/发，**大量耐力伤害**（stamina）——命中即瘫，需多发

### 4.3 吞噬 Devour（成体）

- `devour_lad`：把可吞噬目标**整个吞下**（13.5 秒动画）
- 目标需 `can_consume`（可吞食判定）
- 被吞者 = 缓慢消化（异形移动速度 1.5/喷吐速度 1 相关）

## 七、俘虏异形（Captive Xeno）

**俘虏异形**（`/datum/antagonist/xeno/captive`）——**科研站捕获研究用异形**模式：

| 项 | 值 |
|---|---|
| 团队 | `/datum/team/xeno/captive`（"Captive Aliens" 俘虏异形）|
| 始祖 | `progenitor`（第一只，通常是皇后）|
| 目标 | **escape_captivity 逃出囚禁**："Escape from captivity."（离开俘虏区即完成）|
| 判定 | 离开 `captivity_area` = 逃脱 ✅ / 留在区内 = 失败 ❌ / 死亡 = 阵亡 💀 |

**回合结束报告**：
- 统计：逃出数 vs 留在囚禁数 vs 逃亡中死亡数
- 始祖结局单独播报
- 动态致谢语：若留在囚禁的多 → "Nanotrasen 感谢船员提供**异形生化防护架构**研究数据"；若逃出的多 → "感谢船员提供**异形战斗效能**研究数据"（嘲讽拉满）

**触发条件**：`communications_controller.xenomorph_egg_delivered`（异形卵已送达）且身处俘虏区 → mind 自动分配 captive 变体。

## 九、对战攻略

### 怎么玩异形（成长路线推荐）

```
① 破胸幼虫期（25HP）：立刻躲！找通风管/角落
   - amount_grown 每 tick +1，100 满后可进化
   - 别暴露——人类空手 1-9 伤都可能打死你
② 成体选择：
   - 想打架 → 战士 Hunter（-0.3 速度全异形最快 + 扑击）
   - 想远程 → 哨兵 Sentinel（神经毒素 50P）
   - 想基建 → 无人机 Drone（大型等离子舱，树脂/草/腐蚀开路）
③ 无人机 → 禁卫（500P）→ 皇后（500P）：
   - 禁卫 250HP + 排斥法阵，开团先锋
   - 皇后 500HP/50伤 + 产卵——**蜂巢核心，千万别死**
④ 皇后产卵 → 抱脸虫 → 感染更多船员 → 扩大蜂巢
⑤ 团队目标：存活 + 扩张（advance the Hive）
```

### 怎么杀异形（船员对策）

| 方法 | 说明 |
|---|---|
| **面罩/头盔** | 抱脸虫无法附着（CanHug 检查面具槽）——**医护/安保必备** |
| 太空霉素 | 胚胎生长 ×2 慢一倍——疑似感染立即注射争取手术时间 |
| 手术取胚 | 胚胎第 6 阶段破胸前手术（皮开/锯骨状态可避免 gib）——医疗扫描看 "Stage X/6" |
| 火焰/燃烧 | 异形是生物，火焰武器有效（无特殊抗性） |
| 别被酸开路 | 发现墙被腐蚀/树脂封路 = 异形巢穴已成型，呼叫安保清巢 |
| 皇后优先 | 杀皇后 = 断产卵/晋升/感染链，蜂巢瘫痪 |
| 反制扑击 | 战士扑击落地有硬直——拉开距离/背靠墙 |
| 反制神经毒素 | 命中即耐力打空——保持距离别被连发 |
