## 一、核心概念

**血虫**（`/mob/living/basic/blood_worm`）是寄生型反派：以血为食、以人为壳、以团队为单位的成长流玩法。

**核心设计**：
- **血 = 一切**：你的血条就是宿主的血量；进食（吸血）既回血又攒成长值
- **三阶段成长**：孵化体（Hatchling）→ 幼体（Juvenile）→ 成体（Adult），每阶段体型/伤害/能力全面升级
- **附身机制**：钻入人类体内控制其行动，宿主死亡/失血则被弹出
- **团队协作**：所有血虫同属一个团队（GLOB.blood_worm_team），共享进食进度，可互帮互救

**基础属性**（所有阶段通用）:
| 项 | 值 |
|---|---|
| 阵营 | `FACTION_BLOOD_WORM`（血虫阵营） |
| 语言 | `language_holder/blood_worm`（虫语） |
| 生物类型 | MOB_ORGANIC（有机体）|
| 易燃 | FLAMMABLE_MOB（**怕火**） |
| 眩晕免疫 | status_flags = CANPUSH（**无 CANSTUN，天生免疫眩晕**） |
| 伤害系数 | BRUTE 1 / **BURN 1.5（怕燃烧）** / TOX 0 / STAMINA 0 / OXY 0 |
| 气压抗性 | 200（可在低压环境存活） |
| 呼吸 | 无（breathless，不需要氧气） |
| 生存温度 | T0C-100 ~ T0C+100（-100°C ~ +100°C） |
| 低血压伤害 | 0（低压无害，只有高温/低温有伤害） |
| 视觉 | 红色色调滤镜（lighting_cutoff 40/20/20） |
| HUD | TRAIT_BLOOD_HUD（**血 HUD——能看见生物血量**） |
| 自伤免疫 | anti_self_harm 元素 |

**识别号**：每条血虫有随机 `id_number`（1-999），名字格式"血虫 (ID)"，成长阶段继承同一编号。

## 三、能力详解（行动全录）

### 3.1 吸血 Leech（核心，各阶段通用）

| 项 | 值 |
|---|---|
| 冷却 | **5 秒** |
| 目标 | 活物（吸血）/ 血容器（血袋等）|
| 孵化体速率 | 28 单位血/次（BLOOD_VOLUME_NORMAL×0.05）|
| 幼体速率 | 42 单位血/次（×0.075）|
| 成体速率 | 56 单位血/次（×0.1）|
| 伤害形式 | 吸血期间目标被限制行动（incapacitate）|
| 合成血 | 按 `synth_blood_efficiency = 0.7` 折算（合成血只算 70%）|

**细节**：
- 对**活物**：持续吸血，目标失去血量，血虫获得等量"进食值"（合成血打折）
- 对**容器**（血袋/试剂容器）：抽取其中的血液试剂
- 目标血量 0 时停止；吸血中目标被定身

### 3.2 喷血 Spit（腐蚀弹）

| 阶段 | 生命消耗 | 弹伤害 | 备注 |
|---|---|---|---|
| 幼体 | 5.5/发 | **20**（BURN）| 满血 20 连发（≈300 总伤）|
| 成体 | 6.5/发 | **25**（BURN）| 满血 26 连发（≈500 总伤）|
| 成体爆射 | — | 15×3（BURN）| 右键三连爆射，75 总伤 |

**细节**：
- 冷却 0（只要生命够就能连喷）
- **健康就是弹药**：每发耗血，血虫血量 = 宿主血量，喷血=烧自己的命
- 伤害类型 BURN（受目标护甲影响）
- **右键特殊**：寄居宿主时右键 = **融化束缚**（手铐/脚铐/衣柜/蜘蛛茧）——被逮捕时的越狱神技
- 最小生命 10（低于 10 无法喷）

### 3.3 注入输血 Transfuse（治疗宿主）

| 阶段 | 生命消耗 | 冷却 | 效果 |
|---|---|---|---|
| 孵化体 | 20 | 30s | 治疗 6 HP/s × 20s = **120 HP** |
| 幼体 | 35 | 40s | 治疗 8 HP/s × 20s = **160 HP** |
| 成体 | 50 | 50s | 治疗 10 HP/s × 20s = **200 HP** + 器官修复 5/s |

**细节**：把自己的血注入宿主伤口，快速愈合（伤害/伤口/器官三通道）；耗自己血换宿主命。**宿主血=自己血**，所以要保持宿主健康。

### 3.4 复活宿主 Revive

- 冷却 30s
- 用血把**死透的宿主**复活（需要脑未毁 + 血量充足）
- 配合 STABLEHEART/STABLELIVER/NOCRITDAMAGE 特质，血虫可以反复利用同一具身体

### 3.5 钻入尸体 Invade

- 冷却 0
- 对尸体/濒死人类使用 → 进入其体内
- 宿主血量 + 虫血量换算后必须 > 弹射阈值（见 4.2），否则无法入侵（血太少的尸体进不去）

### 3.6 弹出宿主 Eject

- 冷却 0
- 主动离开宿主（带抖动动画）
- 离开后宿主死亡（unregister_host 强制 death()）

### 3.7 结茧 Cocoon（成长/繁殖）

| 阶段 | 目标 | 需求 | 茧防御 | 产物 |
|---|---|---|---|---|
| 孵化体 | 成长 | **500 血** | 10 | 蜕变为幼体 |
| 幼体 | 成长 | **1,500 血** | 15 | 蜕变为成体 |
| 成体 | 繁殖 | **0 血**（无条件）| 20 | 产出**多个新孵化体**（见下）|

**茧机制**（30s 冷却）：
- 结茧时进入茧结构，消耗已进食的血量，期间**不可被打断即失败**（被打断损失进度）
- 观察者靠近会被**弹飞**（`range = 4 - 距离`）
- 成体结茧：从候选幽灵中抽取 `num_hatchlings` 名 → 每名生成一个新孵化体（繁殖链）→ 向被拒绝的候选人发道歉信

**polymorph 变体**：茧可被变形法术（polymorph）干扰，蜕变成 polymorph 亚种。

## 四、宿主机制（附身/控制/血液联动）

### 4.1 附身流程

```
① 钻入（invade）：虫子进入人类体内（动画 "invade-阶段名" 2 秒）
② 寄生（enter_host）：
   - 宿主获得特质群（TRAIT_INCAPACITATED/IMMOBILIZED/MUTE/EMOTEMUTE + NOBREATH/STABLEHEART/STABLELIVER/NOCRITDAMAGE/NOHUNGER/NO_WITHDRAWALS/NO_SPLIT_PERSONALITY/BLOOD_HUD/BLOOD_WORM_HOST）
   - 宿主流血系数 ×1.5（BLOOD_WORM_BLEED_MOD）
   - 宿主获得"徒手塞器官"能力（hand_organ_insertion）
   - 虫的先天能力 → 换成宿主能力（行动列表切换）
③ 控制（possess_host）：虫的意识进入宿主（宿主 mind 被移到"后座"backseat）
   - 若宿主是变形怪（changeling），保留其意识以使用 Expel Worm
   - 虫获得宿主控制权 + 虫语
④ 离体（leave_host）：弹出，宿主死亡
```

### 4.2 血液联动（核心机制）

```
虫血量 ↔ 宿主血量 直接换算:
  BLOOD_WORM_BLOOD_TO_HEALTH = 100 / BLOOD_VOLUME_NORMAL
  BLOOD_WORM_HEALTH_TO_BLOOD = BLOOD_VOLUME_NORMAL / 100

宿主的血量被限制为: 虫 maxHealth × 换算系数
（即宿主血量上限 = 虫满血对应血量）
宿主血量 = 虫血量 → 虫受的伤 = 宿主失血
```

**弹射阈值**（EJECT_THRESHOLD = 0.1）：
- 宿主血量降到 **虫满血对应血量的 10%** → 虫被强制弹出（"你的血不够控制宿主了！"）
- 弹出瞬间：**宿主立即死亡**（unregister_host 强制 death()，无视一切不死特质）

### 4.3 宿主保护（寄生期间）

| 机制 | 效果 |
|---|---|
| 氧气伤害 | 完全免疫（on_host_adjust_oxy_damage 拦截）|
| 失血耗氧/耗营养 | 免疫（HANDLE_BLOOD_NO_OXYLOSS / NO_NUTRITION_DRAIN）|
| 体温 | 恒定 T20C（宿主在虫体内时虫温恒 20°C）|
| 高温 | 宿主 coretemp > 生存上限 → 虫持续烧伤（unsuitable_heat_damage × BURN系数）|
| 失血警告 | 宿主流血 >0 → 15s 冷却警告"你的宿主在流血！" |
| 高温警告 | 宿主过烫 → 15s 冷却警告"你的血在燃烧！" |

### 4.4 HUD 与状态

- 宿主获得**血条 HUD**（blood_level 屏幕对象）
- 状态栏显示：`Worm Health: xx%` + 已进食血/成长需求

## 五、成长与繁殖（茧/蜕变）

**进食计量**：
```
consumed_blood = consumed_normal_blood + min(consumed_synth_blood, 1000上限) × 0.7效率
进食时: normal 血全额计入；synth 血（猴子/复制血）×0.7
达到 total_blood_required（500/1500）→ 可结茧
结茧消耗全部进食值 → 蜕变为下一阶段
```

**繁殖**（成体）：成体结茧不需要血（total_blood_required = 0），产出 N 个新孵化体 → 一个成体能拉起一支小虫队。

**代码注**：茧需要保护——被打断 = 成长失败；靠近的倒霉蛋会被弹飞。

## 七、血虫与进食系统

### 7.1 血虫肉（战利品）

- 屠宰孵化体/幼体/成体 → 血虫肉 ×1/2/3
- 可烤制：血虫肉 → 血虫牛排（30~90s 烤制，含"三分熟"彩蛋注释）

### 7.2 血液容器

- 可对**血袋/试剂容器**吸血（容器内的血液试剂）
- 吸血时检测容器合成血比例（synth_content）→ 计算成长值

### 7.3 血虫测试仪（Blood Worm Tester）

- 右键生物使用：造成 10-15 伤害（BRUTE，不可致伤）
- 用途：确认目标是否为血虫宿主（血虫对测试仪有特殊 examine 反馈）

### 7.4 特殊交互

- `FIND_BLOOD_WORM(mob)`：检测目标体内是否有血虫（isbloodworm 或 TRAIT_BLOOD_WORM_HOST）
- 血虫 examine 生物时：显示血量 + 成长潜力（"这具身体有 X 单位血，可提供 Y% 成长"）

## 八、对战攻略

### 怎么玩血虫（成长路线推荐）

```
① 孵化体期（0-500血）：苟！钻通风管，咬猴子/尸体/血袋攒血
   - 别惹武装目标——你只有 80HP 和 12-14 伤
   - 优先找"软"目标：昏迷者、独处的医生、失血者
② 钻宿主（500血前也可）：进人身体→用宿主身份行动（偷吃、搞物资）
   - 宿主血=你的血，保持宿主健康就是保命
   - 被抓/被铐→右键喷血融铐（宿主内专属）
③ 幼体期（500-1500血）：可以正面打了
   - 18-22伤+30穿甲，能破气闸——但别碰武装安保
   - 用喷血弹远程消耗（20伤/发，5.5血）
④ 成体期（1500血+）：猎人时间
   - 25-30伤+50穿甲，连高级武器都难挡
   - 喷血爆射（15×3）+喷血弹（25）混合输出
   - 繁殖：结茧产新孵化体，拉起虫群
⑤ 团队目标：清指挥层 / 吃够 2000-3000 真血
```

### 怎么杀血虫（船员对策）

| 方法 | 说明 |
|---|---|
| **火焰/激光** | BURN 伤害 ×1.5——**最有效**。火焰喷射器/激光枪/燃烧瓶都能重创 |
| 找出宿主 | 血 HUD 看不到？看行为异常 + 用血虫测试仪（10-15 伤验证）|
| 别让它进食 | 血=命。拖住它吸血 = 压它血线 |
| 拆宿主 | 血虫在人体内时打空宿主血 → 虫被强制弹出（10%阈值）→ 弹出即杀宿主 |
| 通风管堵截 | 孵化体靠爬管逃命——堵住维修通道/放火熏管 |
| 拆茧 | 虫结茧成长时打断 = 浪费它的进度 |
| 安保武器 | 高级穿甲武器能破成体的 50 穿甲吗？不能——但燃烧类可以 |
